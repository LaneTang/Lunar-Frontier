# Lunar Frontier

> 游戏不是效率模拟器，是文明推演器。

Lunar Frontier（月球开拓者）是一款硬科幻月球殖民模拟游戏。玩家在近未来管理一座名为 **Moontopia** 的月球城市，在生命维持的硬约束与多方势力的政治博弈之间做出抉择，最终建造电磁质量投射器，将月球变为人类走向深空的跳板。

**当前阶段：脑暴（Brainstorming）**

---

## 为什么做这个

人类即将登上月球和火星。对未来文明形态的预测与推演，不应该只留给科幻作家和政策制定者。

电影可以展示一种未来，但只有游戏可以让玩家亲手参与未来的建构。

这不是科幻。NASA 的阿尔忒弥斯基地、SpaceX 的月球自生长城市、中国的国际月球科研站、GRU Space 的月球酒店，这些就是游戏里三个阶段在现实中的映射。游戏的时间线甚至可能比现实更保守。

## 核心设计

### 一分钟体验

地球又送上来一批开拓者，但供氧系统不够了。文明发展理事会面临选择：

- **A：进口氧气。** 下一批火箭直接订购氧气，短期快速填补缺口。但发射配额被占用，下个月没法运建材。
- **B：扩建制氧厂。** 消耗更多资源和时间在月球上扩建氧气生产设施，长期提高供氧量。这一个月会很难熬，但之后氧气产能翻倍。

这个决策就是 Lunar Frontier 的核心心跳。**进口 vs 自产**，贯穿每一种资源、每一个发展阶段。

### 两个系统

| 系统 | 性质 | 内容 |
|------|------|------|
| 生命维持系统 | 硬约束 | 氧气、水、食物、电力、温度、辐射防护。人类无法在月球上直接生存。 |
| 理事会政治系统 | 软约束 | 各方势力在理事会有代表，各有期望。NASA 要科研产出，SpaceX 要加注设施，旅游公司要安全保障。 |

两个系统互相拉扯，争夺同一个东西：**发射配额**。生命维持说"氧气不够了必须进口"，NASA 代表说"进口氧气占用了发射配额，我的实验设备运不上来"。

### 三阶段叙事弧线

1. **求生**：我会不会死？电力、氧气、水，每一个都是生存拷问。
2. **商业化**：我怎么赚钱？旅游、科研合同、矿业订单。基地开始出现非功能性建筑。
3. **宏伟工程**：我怎么统筹全月球的产能？质量投射器是天际线的主角。

每个阶段切换时，玩家的核心焦虑自然转移，不需要任务系统来告诉玩家"现在该干什么"。

### 质量投射器

大多数沙盒模拟游戏没有"赢"的概念。Lunar Frontier 给玩家一个史诗级的终点：电磁质量投射器。

这不是奇观，是逻辑终点。月球的价值不在月球本身，在于低重力环境下的廉价发射。质量投射器让月球成为地球的船坞，人类走向深空的跳板。

> SpaceX 2026 年内部信明确提到："By using an electromagnetic mass driver and lunar manufacturing, it is possible to put 500 to 1000 TW/year of AI satellites into deep space." 游戏的终局目标和现实中最激进的商业航天计划完全吻合。

## Moontopia

Moontopia 是玩家推演中的近未来月球城市。它不是拉斯维加斯，不是伊甸园，它是一个**码头**。

- **功能型城市**：服务于"让人类去更远的地方"这个目的。码头、船坞、加油站。
- **UN 式中立治理**：独立政治团体，各方人士联合组成，立场绝对中立。一个没有国旗的码头。
- **平台模式**：Moontopia 建公共基础设施（电力、水、空气、着陆场），各方势力租用进驻、自建自营。国旗插在自己的建筑上。
- **玩家身份**：文明发展理事会。不是一个人说了算，而是"理事会经过讨论后的集体意志"。从"我命令"变成"我们决定"。

## 品类参考

- **纪元 1800**：需求驱动扩张。你不会因为"想建钢铁厂"而建钢铁厂，是因为工人需要肥皂，肥皂需要油脂，油脂需要养猪场。幸福度是经济引擎。
- **冰汽时代 2**：从微观到宏观的视角转换。议会系统。势力是客户不是人民，不满意可以走。暖券（税收）是一切经济活动的血液。
- **戴森球计划**：科技 + 工业双轨制，行星级物流。
- **缺氧**：生命维持精细管理，管道可视化。
